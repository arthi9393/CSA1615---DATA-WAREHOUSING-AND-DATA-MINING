WEKA FILES — QUESTIONS 1–40

All files are placed directly in this ZIP; there are no question folders.

For each question, look for files beginning with its number (for example, Q01_). Open the matching .arff dataset in WEKA Explorer and follow the matching _Instructions.txt file. Some questions reuse the same dataset, so a question-prefixed copy is included for each one.

WEKA tasks are performed through the WEKA GUI using the supplied ARFF files and instructions; they are not standalone Java programs.

Source mismatch note: Questions 17 and 18 describe house-price regression, but the assignment supplies an Employee Missing dataset instead. The supplied data is retained and the instructions flag this mismatch; no house-price data has been invented.
